Scraper Architecture & System Specifications

1. Reliable Extraction (Selenium)

Uses Selenium WebDriver with Google Chrome in --headless=new mode with anti-bot fingerprint masking to reliably render dynamic JavaScript DOM elements.

2. Daily Up-to-Date Scheduler

Powered by APScheduler running as a background daemon on 02:00 AM daily cron to track rating drifts and maintain up-to-date data.

3. Custom Data Use (CSV / ML / Analytics)

Pre-structured UTF-8-SIG CSV ready for ingestion in Pandas, Scikit-learn recommendation engines, Power BI, or Tableau dashboards.

5. Expandable Micro-Scraper

On-demand scraping worker targeting individual movie URLs for deep metadata: Director, Top Cast, Sub-Genres, and Storyline Plot.
